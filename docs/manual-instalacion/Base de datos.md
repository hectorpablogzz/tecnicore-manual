---

## Requisitos

- Herramienta de gestión y desarrollo de bases de datos (por ejemplo, DBeaver o MySQL Workbench).
- Conexión activa a internet o red local.
- Permitir acceso en el firewall o antivirus para evitar bloqueos de conexión.

---
